# 小红书情绪种草到搜索成交 Skill

这个仓库用于存放可复用的 ChatGPT/Codex Skill：

`小红书情绪种草到搜索成交 Skill`

它不是爆款工具，不是流量增长工具，也不是普通文案润色工具。

核心任务是帮助商家先弄清楚：

- 卖给谁
- 怎么种草
- 用户搜什么
- 凭什么信你
- 看完怎么行动

主链路：

`产品/服务翻译 -> 情绪种草 -> 搜索承接 -> 信任建立 -> 行动转化`
