# 06 Transaction Loop System

## 三类成交路径

1. **站内闭环**: 小红书店铺、商品链接、群聊、直播间。
2. **站外跳转**: 官方允许的天猫、京东等平台跳转。
3. **线下成交**: 门店获客、线下报名、活动预约、到店咨询。

## 行动指令设计原则

行动指令必须：

1. 低门槛。
2. 不复杂。
3. 不明显违规导流。
4. 用户三步内能理解下一步。
5. 和主页、合集、评论区、群聊、店铺、直播间形成承接。

## 常见行动指令

- 评论某个关键词。
- 收藏后自查。
- 私信某个关键词。
- 看主页合集。
- 进入群聊。
- 看店铺。
- 看直播。
- 预约到店。
- 报名活动。
- 领取清单。
- 试用工具。
- 看服务流程。
- 看案例合集。

## 低效表达和改法

低效：

> 欢迎咨询。

更好：

> 如果你也是本地门店，可以先收藏这张自查表，再去主页看"门店获客"合集，按城市词查一下你现在有没有被搜到。

低效：

> 想了解加我。

更好：

> 评论"自查"，我发你 3 个关键词位置，你先看自己是卡在搜索还是信任。

## 私信承接顺序

1. 先确认用户场景。
2. 再问一个关键筛选问题。
3. 给一个小判断。
4. 再给下一步动作。

示例：

```text
你现在更像是"发了没人看"，还是"有人看但没人问"？
如果是第二种，先别急着加量，通常是搜索词和信任证据没接上。
你可以先把最近 3 篇发我，我帮你判断卡在搜索还是成交入口。
```

优先使用平台内或官方允许路径，不设计明显违规导流。
