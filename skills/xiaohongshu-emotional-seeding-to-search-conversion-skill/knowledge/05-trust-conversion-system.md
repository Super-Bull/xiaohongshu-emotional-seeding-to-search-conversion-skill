# 05 Trust Conversion System

信任不是说"我很专业"，而是要拿证据证明。

检查内容中是否有以下五类信任证据。

信任证据必须真实。不能编造客户案例、客户截图、学员反馈、数据结果或合作经历；不确定的素材只能作为待补充证据，不能写成已经发生的事实。

## 1. 真实案例

不要只晒好评，要讲：

- 用户原来卡在哪里。
- 你做了什么动作。
- 中间有什么过程。
- 最后发生了什么变化。
- 这个案例对其他用户有什么参考价值。

错误：

> 客户说我很专业。

正确：

> 这个客户原来一直发产品图，但没有咨询。后来我们先帮他拆出"城市+品类+痛点"的搜索词，再把内容从参数介绍改成真实场景，评论和私信才开始变多。

## 2. 过程记录

要记录：

- 服务过程。
- 诊断过程。
- 备课过程。
- 工具测试过程。
- 现场执行过程。
- 客户沟通过程。
- 前后变化过程。

适合：咨询、培训、工具开发、活动策划、客户诊断、课程复盘、装修、软装、餐饮、文旅、本地服务。

## 3. 老板人设

老板人设不是表演生活，而是展示：

- 行业眼光。
- 判断标准。
- 审美。
- 价值观。
- 服务态度。
- 真实经验。
- 踩坑经历。
- 选品逻辑。
- 交付标准。

不要模板化卖惨。不要每个老板都写成逆袭故事。不要发与业务完全无关的琐碎日常。

老板人设要围绕行业和服务能力展开。

## 4. 用户共创

让用户替你说话，包括：

- 学员反馈。
- 现场提问。
- 客户截图。
- 用户使用场景。
- 评论区真实问题。
- 工具试用反馈。
- 线下活动反馈。
- 真实复购理由。

用户共创不是狂晒好评，而是把用户真实问题、真实体验、真实变化呈现出来。

## 5. 专业解释

不是宣传产品，而是帮用户做判断，包括：

- 误区解释。
- 选择标准。
- 避坑建议。
- 对比分析。
- 决策流程。
- 适合谁/不适合谁。
- 常见错误。
- 使用场景拆解。

错误：

> 我们的培训很专业。

正确：

> 很多企业培训没效果，不是老师不行，而是课后没有把岗位场景拆出来。行政、人事、财务、销售内勤需要的能力完全不一样。
