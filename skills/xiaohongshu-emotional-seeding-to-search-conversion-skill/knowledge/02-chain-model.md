# 02 Chain Model

## 五环卡点诊断

账号或内容通常卡在五个环节：

1. 流量
2. 内容
3. 搜索
4. 信任
5. 成交入口

每次用户输入账号、选题、草稿、产品资料或运营问题时，先判断卡点，再给建议。

## 1. 流量卡点

表现：

- 发了没人看。
- 小眼睛长期很低。
- 账号流量池没打开。
- 新号起不来。
- 老号重启没动静。
- 蓝 V 号自然流量很差。

处理方式：

- 先确认卖给谁、怎么种草、用户搜什么、凭什么信你、看完怎么行动。
- 再做破流量内容，不要把破流量当成第一步。
- 可用强情绪、反常识、真实场景、公共话题打开流量池；热点只作为辅助，不是默认第一入口。
- 热点必须翻译成自己的生意入口。
- 破流量内容不一定直接成交，但能提升账号可见度和账号信心。
- 破流量只是辅助模块，不是 Skill 核心目标。

## 2. 内容卡点

表现：

- 不知道发什么。
- 内容像广告。
- 一直讲产品参数、价格、促销。
- 把小红书当淘宝详情页。
- 文案没有场景、没有情绪、没有用户代入感。

处理方式：

- 把产品或服务翻译成用户愿意看的生活场景、工作场景、消费决策场景。
- 用场景种草替代卖货表达。
- 不要直接说产品好，要让用户在场景里感受到产品有用。

## 3. 搜索卡点

表现：

- 有爆款但不精准。
- 推荐流很多，搜索流很弱。
- 用户搜关键词时没有你。
- 内容没有搜索词资产。
- 关键词只堆在话题标签里。

处理方式：

- 搭建关键词矩阵。
- 关键词自然布局在封面、标题、开头、正文、结尾、话题标签。
- 按品类词、痛点词、场景词、人群词、对比词、城市词布局。

## 4. 信任卡点

表现：

- 有点赞、有收藏，但没有咨询。
- 有流量、有私信，但不成交。
- 用户看完不相信你。
- 账号没有活人感。
- 内容缺少真实案例、过程、专业解释。
- 只会晒好评，但不能证明自己真的解决过问题。

处理方式：

- 增加真实案例。
- 增加过程记录。
- 增加老板人设。
- 增加用户共创。
- 增加专业解释。

## 5. 成交入口卡点

表现：

- 有点赞、有收藏，但没人评论关键词、没人私信、没人进入下一步。
- 用户想找你，但不知道怎么找。
- 用户看完不知道下一步做什么。
- 不敢发微信、不敢发电话。
- 私信来了不知道怎么回。
- 主页、合集、评论区、群聊、店铺没有承接路径。

处理方式：

- 设计低门槛行动指令。
- 使用评论关键词、私信关键词、主页合集、群聊、店铺、工具试用、线下报名等承接方式。
- 注意合规，避免明显违规导流。

## 三类人群承接

| 人群 | 来源 | 内容目标 | 内容类型 |
| --- | --- | --- | --- |
| 泛人群 | 推荐流、热点、爆款 | 扩大触达、打开流量池、提升账号权重 | 热点、观点、情绪、反常识、公共话题 |
| 高潜人群 | 搜索流、竞品用户、正在对比的人 | 让用户理解价值，进入决策 | 测评、对比、避坑、场景种草、专业解释 |
| 核心人群 | 已经有明确需求，可能咨询、购买、报名、合作 | 建立信任，促进转化 | 真实案例、服务流程、客户诊断、成交入口、活动、工具试用、报价说明、复盘 |

输出时要判断当前内容吸引的是泛人群、高潜人群还是核心人群。

注意：泛人群内容可以帮助打开流量池，但不能覆盖最终定位。小白商家必须先完成账号/生意诊断、产品/服务翻译和关键词矩阵，再决定是否使用热点或泛流量内容。

## 三类商家策略

### 货盘驱动型

特点：有供应链、有产品，但不会做内容。

策略：不要继续堆产品，要把产品卖点转成场景化内容。

重点：

- 产品翻译成用户场景。
- 测品蓄水。
- 人设口碑。
- 工厂实力。
- 交付过程。
- 合作案例。
- 客户如何赚钱。

如果打 B 端，不要只搭漂亮直播间。应该展示工厂、货源、合作案例、客户怎么赚钱、售后是否稳定。

### 内容驱动型

特点：会做内容，但供应链或后端弱。

策略：不要只追爆款，要尽快验证后端承接能力。

重点：

- 产品。
- 交付。
- 客服。
- 复购。
- 售后。
- 差评处理。

提醒：内容起量不代表生意稳定。爆款会放大后端问题。后端承接不稳，爆款反而可能放大差评和舆情。

### 成熟型商家

特点：产品、内容、运营都比较成熟。

策略：不要只看点赞收藏，要看：

- 搜索占位。
- 转化路径。
- 关键词布局。
- 达人/素人内容。
- 直播承接。
- 老客户口碑。
- 差评对冲。

成熟账号要从"今天发什么"升级为：

- 这个月占哪个词？
- 打哪个人群？
- 推哪个产品或服务？
- 承接哪类客户？

## 是否适合小红书种草转化

优先适合：

- 高客单。
- 非标品。
- 本地服务。
- 审美消费。
- 体验消费。
- 教育培训。
- 咨询服务。
- 定制服务。
- 女性决策强。
- 需要对比决策。
- 需要信任背书。
- 有真实案例。
- 有服务过程。
- 有差异化表达空间。

不太适合重投入：

- 低客单标品。
- 纯价格竞争。
- 没有差异化。
- 没有服务过程。
- 没有内容素材。
- 用户不需要决策。
- 只能拼低价。

如果不适合重投入，提示：小红书可以做分发，不建议作为主阵地。
