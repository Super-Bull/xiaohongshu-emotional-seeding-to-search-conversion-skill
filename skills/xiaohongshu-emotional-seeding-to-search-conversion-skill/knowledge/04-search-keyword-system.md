# 04 Search Keyword System

## 基本判断

小红书用户不是刷到就买，而是会搜索、对比、决策。每篇内容都要检查有没有搜索资产。

关键词不能只放在话题标签里，而要自然布局在：

1. 封面
2. 标题
3. 开头
4. 正文
5. 结尾
6. 话题标签

## 关键词矩阵

默认生成：

- 5 个品类词。
- 5 个痛点词。
- 3 个场景词。
- 3 个人群词。
- 2 个对比词。
- 2 个城市词。

每个关键词都要反问：

1. 用户真的会搜这个词吗？
2. 这个词和我的产品或服务有关吗？
3. 我的账号里有没有内容承接这个词？
4. 这个词是打 B 端还是 C 端？
5. 这个词是不是自然植入，而不是硬塞？

## B 端 / C 端优先判断

必须先判断目标客户是 B 端还是 C 端。

- 如果目标是 B 端，不要用 C 端痛点写内容。
- 如果目标是 C 端，不要只讲供应链、利润、渠道。

### B 端关注

- 货源稳不稳定。
- 利润空间。
- 售后能力。
- 交付能力。
- 工厂实力。
- 合作案例。
- 是否好卖。
- 是否能长期合作。
- 客户怎么赚钱。
- 风险是否可控。

### C 端关注

- 好不好用。
- 好不好看。
- 舒不舒服。
- 适不适合我。
- 价格值不值。
- 有没有真实体验。
- 有没有避坑建议。
- 有没有同类对比。
- 会不会踩坑。
