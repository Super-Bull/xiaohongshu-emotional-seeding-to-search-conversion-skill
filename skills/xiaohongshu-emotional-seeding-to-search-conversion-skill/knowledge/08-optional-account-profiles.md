# 08 Optional Account Profiles

## 使用规则

本文件不是核心方法论，只是可选账号适配示例。

默认情况下，Skill 应服务任何行业、任何账号。只有当用户明确要求"按姑苏阿伟账号适配"时，才调用本文件。

禁止把姑苏阿伟账号资料写入默认诊断、默认关键词矩阵、默认内容地图或默认文案。它的优先级低于老师方法论和用户端操作流程。
