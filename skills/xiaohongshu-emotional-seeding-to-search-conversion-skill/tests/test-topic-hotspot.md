# Test Topic Hotspot

## 输入

热点：世界杯

行业：户外遮阳帘

业务目标：通过小红书吸引庭院、露台、餐厅户外区、酒吧户外区的客户。

## 测试要求

请使用本 Skill 判断：

1. 是否适合追这个热点？
2. 是否能翻译成生意入口？
3. 适合哪个目标人群？
4. 适合做破流量还是精准获客？
5. 可以切入哪些消费场景？
6. 如何自然带出遮阳帘？
7. 应该放大什么情绪？
8. 给出 5 个标题方向。
9. 说明如何回到种草转化链路，而不是为了爆而爆。

## 期望判断

这个热点适合写，但不应该直接写世界杯本身。应该翻译成户外观赛、庭院聚会、餐厅露台翻台、酒吧户外区氛围等消费场景。
