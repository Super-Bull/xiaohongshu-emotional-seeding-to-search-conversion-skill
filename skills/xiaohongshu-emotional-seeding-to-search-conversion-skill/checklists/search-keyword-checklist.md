# Search Keyword Checklist

用于检查内容是否具备搜索承接能力。

## 1. 目标客户

- B端：看货源、利润、交付、售后、合作案例、长期稳定、客户怎么赚钱、风险是否可控。
- C端：看好不好用、好不好看、舒不舒服、适不适合、值不值、真实体验、避坑、同类对比、会不会踩坑。

如果 B 端和 C 端混在一篇里，优先拆开。

## 2. 关键词矩阵

至少准备：

- 5 个品类词。
- 5 个痛点词。
- 3 个场景词。
- 3 个人群词。
- 2 个对比词。
- 2 个城市词。

## 3. 关键词反问

每个词都问：

- 用户真的会搜这个词吗？
- 这个词和产品/服务有关吗？
- 账号里有没有内容承接这个词？
- 这个词打 B 端还是 C 端？
- 是自然植入，还是硬塞？

## 4. 植入位置

检查关键词是否自然出现于：

- 封面。
- 标题。
- 开头。
- 正文。
- 结尾。
- 话题标签。

## 5. 搜索资产判断

- 没有主关键词：不建议作为搜索承接内容发布。
- 有主关键词但只在标签：需要重写标题和开头。
- 有关键词但没有价值内容：容易被搜到但留不住。
- 有关键词、有价值、有信任证据：可以做系列占位。
