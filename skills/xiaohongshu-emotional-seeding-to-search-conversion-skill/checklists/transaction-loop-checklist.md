# Transaction Loop Checklist

用于检查内容是否有行动转化入口。

## 1. 成交路径

选择当前路径：

- 站内闭环：小红书店铺、商品链接、群聊、直播间。
- 站外跳转：官方允许的天猫、京东等平台跳转。
- 线下成交：门店获客、线下报名、活动预约、到店咨询。
- 未设计：需要先设计承接路径。

## 2. 行动指令

行动指令是否：

- 低门槛。
- 不复杂。
- 不明显违规导流。
- 用户三步内能理解下一步。
- 与主页、合集、评论区、群聊、店铺、直播间形成承接。

## 3. 常见动作

可选：

- 评论某个关键词。
- 收藏后自查。
- 私信某个关键词。
- 看主页合集。
- 进入群聊。
- 看店铺。
- 看直播。
- 预约到店。
- 报名活动。
- 领取清单。
- 试用工具。
- 看服务流程。
- 看案例合集。

## 4. 私信承接

私信回复是否包含：

- 用户场景确认。
- 关键筛选问题。
- 一个小判断。
- 下一步动作。

不要一上来强推产品。

- 承接路径需要补什么：
- 建议行动指令：
- 是否使用平台内或官方允许路径：
