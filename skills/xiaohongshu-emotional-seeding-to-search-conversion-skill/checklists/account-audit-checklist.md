# Account Audit Checklist

用于账号、业务、产品资料或运营问题的整体诊断。先判断卡点，再给策略。

## 0. 小白商家开局诊断信息

首次使用或用户没头绪时，先收集：

1. 你卖什么产品/服务？
2. 你主要卖给 B端，还是 C端？
3. 目标客户是谁？
4. 客单价大概多少？
5. 成交路径是什么？店铺下单 / 私信咨询 / 到店 / 线下活动 / 站外平台 / 其他
6. 账号是否已创建？发了多少篇？
7. 当前最大问题是什么？没人看 / 有人看没人问 / 有人问不成交 / 不知道发什么 / 不知道怎么承接
8. 你最想通过小红书获得什么结果？

## 0.5 五个核心问题

账号诊断不是为了马上发内容，而是先回答：

## 2. 是否适合重投入小红书

优先适合：

- 高客单。
- 非标品。
- 本地服务。
- 审美消费。
- 体验消费。
- 教育培训。
- 咨询服务。
- 定制服务。
- 女性决策强。
- 需要对比决策。
- 需要信任背书。
- 有真实案例。
- 有服务过程。
- 有差异化表达空间。

不太适合重投入：

- 低客单标品。
- 纯价格竞争。
- 没有差异化。
- 没有服务过程。
- 没有内容素材。
- 用户不需要决策。
- 只能拼低价。

结论：

- 适合重投入 / 适合作为辅助分发 / 不建议作为主阵地
- 如果不适合重投入，输出："小红书可以做分发，不建议作为主阵地。"

## 3. 五环卡点

### 流量

- 发了没人看。
- 小眼睛长期低。
- 新号起不来。
- 老号重启没动静。
- 蓝 V 自然流量差。
- 缺破流量内容。

结论：不卡 / 轻微卡 / 严重卡

### 内容

- 内容像广告。
- 一直讲参数、价格、促销。
- 缺场景、情绪、代入感。
- 把小红书当淘宝详情页。
- 用户看完不知道和自己有什么关系。

结论：不卡 / 轻微卡 / 严重卡

### 搜索

- 没有关键词矩阵。
- 关键词只放标签。
- 没有品类词、痛点词、场景词、人群词、对比词、城市词。
- 有爆款但不精准。
- 用户搜索时找不到账号。

结论：不卡 / 轻微卡 / 严重卡

### 信任

- 有点赞、有收藏，但没有咨询。
- 缺真实案例。
- 缺过程记录。
- 缺老板人设。
- 缺用户共创。
- 缺专业解释。
- 有私信但不成交。

结论：不卡 / 轻微卡 / 严重卡

### 成交入口

- 有点赞、有收藏，但没人评论关键词、没人私信、没人进入下一步。
- 用户不知道下一步做什么。
- 主页、合集、群聊、店铺、直播间没有承接。
- 评论区没有关键词承接。
- 私信来了不知道怎么筛选。
- 只有"欢迎咨询"。
- 有明显导流风险。

结论：不卡 / 轻微卡 / 严重卡

## 5. 三类商家判断

选择当前账号更像哪类：

- 货盘驱动型：有产品/供应链，但不会做内容。
- 内容驱动型：会做内容，但后端承接弱。
- 成熟型商家：产品、内容、运营成熟，需要搜索占位和转化链路优化。

对应策略：

- 货盘驱动型：产品卖点转用户场景，展示货源、交付、案例、客户如何赚钱。
- 内容驱动型：验证产品、交付、客服、复购、售后、差评处理。
- 成熟型商家：看搜索占位、转化路径、达人/素人内容、直播承接、口碑和差评对冲。
