# Single Note Audit Checklist

用于质检单篇小红书笔记。

## 1. 内容类型判断

选择一个主任务：

- 破流量内容：打开流量池。
- 情绪种草内容：让用户心动。
- 搜索承接内容：让用户搜到。
- 信任转化内容：让用户相信。
- 行动转化内容：让用户行动。

必须说明：

- 这篇属于哪类内容。
- 它在账号链路里的任务是什么。
- 它不应该同时承担什么任务。
- 下一篇应该补哪类内容。

## 2. 目标人群判断

- 泛人群：推荐流、热点、爆款。
- 高潜人群：搜索流、竞品用户、正在对比的人。
- 核心人群：已有明确需求，可能咨询、购买、报名、合作。

同时判断：

- B端 / C端 / 两者混杂。
- 如果混杂，是否需要拆成两篇。

## 3. 五环诊断

- 流量：封面、标题、情绪、话题是否能打开点击？
- 内容：是否有场景、情绪、价值？
- 搜索：是否有关键词资产？
- 信任：是否有证据？
- 成交入口：是否有低门槛下一步？

## 4. SEVA

- S 场景关联：有 / 弱 / 无
- E 情绪调动：有 / 弱 / 无
- V 价值传递：有 / 弱 / 无
- A 行动指引：有 / 弱 / 无

## 5. 种草转化完成度评分

- 产品/服务翻译：10 分
- 目标人群：10 分
- 场景关联：10 分
- 情绪调动：10 分
- 搜索承接：15 分
- 信任证据：15 分
- 价值传递：10 分
- 行动转化：10 分
- 风险合规：10 分

## 6. 修改优先级

优先改最影响转化的 1-3 个问题：

1. 如果没有场景，先补场景。
2. 如果没有关键词，先补搜索资产。
3. 如果没有信任证据，先补案例/过程/专业解释。
4. 如果没有行动入口，先补低门槛动作。
5. 如果有风险，先降风险再发布。
6. 如果用户没有提供产品/服务、目标客户、B/C 端、成交路径和关键词，先补 5 个信息，不要直接大改文案。
