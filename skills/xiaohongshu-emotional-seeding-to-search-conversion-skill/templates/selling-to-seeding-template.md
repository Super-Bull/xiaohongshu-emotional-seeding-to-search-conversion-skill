# Selling To Seeding Template

用于把卖货笔记改成小红书种草笔记。

这不是普通润色模板。改写前必须先确认卖给谁、怎么种草、用户搜什么、凭什么信你、看完怎么行动；信息不足时先补诊断，不直接改成"好看的文案"。

## 原则

小红书不能当第二个淘宝。

不要一直讲：

- 产品参数。
- 价格。
- 促销。
- 新品上线。
- 欢迎咨询。
- 功能堆叠。
- 官方口吻。

要改成：

- 用户场景。
- 痛点情绪。
- 使用体验。
- 决策参考。
- 真实过程。
- 专业判断。
- 下一步低门槛行动。

## 转换公式

卖货表达：

`我有什么产品或服务 -> 有什么功能 -> 价格优惠 -> 欢迎咨询`

种草表达：

`谁在什么场景遇到什么问题 -> 为什么这个问题很烦 -> 我看到或经历了什么真实案例 -> 这个问题应该怎么解决 -> 用户下一步可以怎么做`

## 通用改写模板

```text
最近很多【目标人群】跟我说：
明明【产品/能力】不差，但【小红书/获客/转化】就是没结果。

我看了几个账号，问题几乎一样：
内容太像货架了，用户根本不知道为什么要现在找你。

今天拿一个真实案例，拆一下：
【某类人/某类商家】怎么从"发产品"改成"让用户主动搜索你"。
```

## 输出结构

必须包含：

1. 原文广告感问题。
2. 用户场景重构。
3. 情绪点重构。
4. 价值点重构。
5. 行动指令重构。
6. 改写后的完整小红书文案。
7. 需要补充的真实证据。
